# Shadow Protocol

A top-down pixel-art stealth game for a Theory of Computation course: every guard is a
deterministic finite automaton (DFA) you can watch and inspect. It also has an NFA ⇄ DFA comparison
mode, an Automata Lab (editor, simulator, subset construction, JSON save/load) and an interactive
tutorial with challenges. Windows desktop app built with Tauri 2, React, TypeScript, Vite and Phaser 3.

Installers and installation instructions for users: `release/Shadow-Protocol-1.0.0/README.txt`.

## Development

Requirements: Node.js, Rust (stable, MSVC toolchain), Windows with the WebView2 runtime.

```bash
npm install
npm run tauri dev    # desktop app with hot reload
npm test             # Vitest unit tests
npm run typecheck    # TypeScript checks
npm run tauri build  # release build + NSIS (.exe) and MSI installers
```

Installers are written to `src-tauri/target/release/bundle/{nsis,msi}/`. The first `tauri build`
downloads the NSIS and WiX tools, so it needs an internet connection.

The app icon is pixel art generated by `scripts/make-icon.py` (Python standard library only):

```bash
python scripts/make-icon.py src-tauri/icons/source-1024.png
npx tauri icon src-tauri/icons/source-1024.png
```

Project structure and conventions are documented in `CLAUDE.md`.
